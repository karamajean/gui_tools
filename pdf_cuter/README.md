# PDF 頁面擷取工具

這是一個使用 C# WinForms 開發的 PDF 頁面擷取工具，可以從 PDF 檔案中提取指定的頁面並保存為新的 PDF 檔案。

## 功能特色

- 🎯 **簡單易用**：直觀的圖形用戶界面
- 📄 **靈活頁面選擇**：支援多種頁面範圍格式
- 🔍 **自動頁數檢測**：載入 PDF 後自動顯示總頁數
- 💾 **批次處理**：支援多頁面範圍的批次擷取
- 🔗 **合併 PDF**：支援選擇多個 PDF 檔案並依指定順序合併為一個檔案
- 🛡️ **錯誤處理**：完善的錯誤提示和驗證

## 頁面範圍格式

支援以下格式的頁面範圍輸入：

- **單一頁面**：`5` (擷取第5頁)
- **連續範圍**：`1-10` (擷取第1到第10頁)
- **多個範圍**：`1-5,8,10-15` (擷取第1-5頁、第8頁、第10-15頁)
- **混合格式**：`1,3-5,7,9-12` (擷取第1頁、第3-5頁、第7頁、第9-12頁)

## 系統需求

- Windows 10 或更新版本
- .NET 6.0 或更新版本
- Visual Studio 2022 (用於開發)

## 安裝與使用

### 方法一：使用 Visual Studio

1. 開啟 Visual Studio 2022
2. 選擇「開啟專案或解決方案」
3. 選擇 `PDFCutter.csproj` 檔案
4. 按 F5 或點擊「開始偵錯」執行

### 方法二：使用命令列

```bash
# 還原 NuGet 套件
dotnet restore

# 建置專案
dotnet build

# 執行應用程式
dotnet run
```

## 使用步驟

1. **選擇輸入檔案**：點擊「選擇檔案」按鈕，選擇要處理的 PDF 檔案
2. **設定輸出位置**：點擊「選擇位置」按鈕，設定新 PDF 檔案的儲存位置
3. **輸入頁面範圍**：在頁面範圍欄位中輸入要擷取的頁面
4. **執行擷取**：點擊「擷取頁面」按鈕開始處理
5. **完成**：等待處理完成，會顯示成功訊息

## 合併多個 PDF

1. 點擊主畫面的「合併多個 PDF 檔案」按鈕，開啟合併視窗
2. 點擊「新增檔案...」選擇多個要合併的 PDF 檔案
3. 使用「上移」／「下移」調整檔案順序（合併後的頁面順序會依此清單由上到下排列）
4. 「與輸入檔案同資料夾」預設為勾選，輸出檔案會自動存到清單第一個檔案所在資料夾（檔名為 `{第一個檔案}_merged.pdf`）；取消勾選才需點擊「選擇位置」自行指定
5. 點擊「開始合併」執行合併

## 注意事項

- 確保輸入的 PDF 檔案沒有密碼保護
- 頁面範圍不能超過 PDF 的實際頁數
- 輸出檔案路徑不能與輸入檔案相同
- 建議在處理大型 PDF 檔案時耐心等待
